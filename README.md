<h3 align="center">MATA</h3>

Lightweight PHP-native monitoring for constrained environments.

- **Dashboard pulls data from nodes.**
- **Nodes never initiate connections.**
- **Nodes are stateless and read-only.**

## Projects

- [MATA Dashboard](https://github.com/mata-sh/mata-dashboard) — web UI, alerting, and management
- [MATA Node](https://github.com/mata-sh/mata-node) — lightweight read-only endpoint deployed per monitored environment

If you are new to MATA, start with the **Dashboard** README.
